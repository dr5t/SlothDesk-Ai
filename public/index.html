SETUP GUIDANCE · LOCAL OPEN-WEIGHT AI

Enabling Gemma 3 with Ollama

SlothDesk AI is strictly local-first and never sends document contents or extracted tasks to external cloud APIs. When Ollama is offline or uninstalled, deterministic local heuristics execute automatically.

TERMINAL COMMANDS LOCAL HOST
$ ollama serve Start the local Ollama background server
$ ollama pull gemma3:4b Download and register the Gemma 3 4B parameter open-weight model
✦ Resilient Fallback: If Ollama is offline, unreachable, or missing the configured model, SlothDesk AI continues running seamlessly using deterministic TypeScript parsing and regex extraction.
