# Five-minute demo

1. Create a temporary demo folder containing two notes, one CSV, and a byte-for-byte duplicate.
2. Start the app with `npm start` and open `http://localhost:3147`.
3. Confirm the health badge reports whether local Ollama/Gemma is available.
4. Enter the absolute demo folder path and run the dry-run scan.
5. Show file counts, duplicate hashes, summaries, extracted tasks, and estimated net minutes saved.
6. Leave one proposal unchecked, approve the rest, and verify the resulting folder.

All results shown by the app come from the selected files and measured execution timestamps; no dashboard statistics are seeded.
